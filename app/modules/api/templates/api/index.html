    Como usar (§16)

    1. Troque a chave por um token de 1 hora:

    curl -X POST {{ request.base_url }}api/token \
  -H "Content-Type: application/json" \
  -d '{"api_key": "sk_..."}'

    2. Use o token nas chamadas:

    curl {{ request.base_url }}api/v1/usuarios \
  -H "Authorization: Bearer <access_token>"

    A documentação completa está no Swagger. Um escopo só funciona se o usuário dono da chave também tiver a permissão.
